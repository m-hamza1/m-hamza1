# Ameer Hamza — Senior Full-Stack & Software Engineer Portfolio

Personal portfolio and engineering showcase built with **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Three.js**.

## Tech Stack
- **Framework**: Next.js 16 (Turbopack, App Router)
- **Frontend**: React 19, Tailwind CSS, Lucide Icons
- **Interactive 3D**: Three.js, React Three Fiber
- **Backend / API**: Next.js Server Routes, Nodemailer
- **Deployments**: Vercel, Linux VPS & cPanel

## Local Development
```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

## Deploying on Vercel
1. Import this repository into [Vercel](https://vercel.com/new).
2. Framework Preset will automatically detect **Next.js**.
3. (Optional) Set SMTP environment variables from `.env.example` in Vercel Project Settings > Environment Variables for the contact form email dispatcher.
4. Click **Deploy**.
